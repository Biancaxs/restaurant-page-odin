# Restaurant Page

🍽️ Elegant restaurant website built with JavaScript, featuring dynamic content rendering, interactive navigation, and a responsive layout.

## Features

* Dynamic page content
* Interactive navigation between sections
* Responsive design
* Modular JavaScript structure
* Clean and intuitive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Webpack

## What I Learned

* JavaScript modules
* DOM manipulation
* Dynamic content rendering
* Webpack and module bundling
* Organizing code into separate modules
* Managing page navigation with JavaScript

## Project Goal

This project was built as part of The Odin Project curriculum to practice JavaScript modules, Webpack, and dynamically generating website content.
